## Модуль 2: Linux

### Окружение Linux

- `/` (Корень) — Начало всей файловой системы. 

- `/etc` — Папка с конфигурациями. Здесь хранятся текстовые настройки самой системы, сети, доступов и всех установленных программ.

- `/var/log` — Журналы событий (Логи). 

- `/bin` и `/sbin` — Системные программы (Бинарники). Здесь физически лежат исполняемые файлы большинства команд, которые мы вводим в консоли.

- `/home` — Личные папки пользователей. Безопасное изолированное пространство. Внутри находится ваша папка `/home/user` (сокращенно `~`).

- `/root` — Личная папка суперпользователя (Администратора). 

### Команды терминала Linux

**Навигация и информация:**
- `pwd` — Показывает полный путь к папке, в которой вы стоите прямо сейчас.

- `ls` — Выводит список всех файлов и папок внутри текущей директории.

- `du -h` — Показывает размер конкретного файла или папки на диске. Флаг `-h` делает цифры понятными для человека (в КБ, МБ, ГБ).

- `df -h` — Выводит общую карту всех жестких дисков компьютера и показывает, сколько на них осталось свободного места.

**Работа с файлами и папками (CRUD):**

- `mkdir` — Создаёт новую пустую папку (директорию).

- `touch` — Создаёт абсолютно пустой текстовый файл.

- `cat` — Мгновенно выводит всё содержимое текстового файла прямо на экран терминала.

- `cp` — Копирует файл или папку в другое место. (Синтаксис: `cp что_копируем куда_копируем`).

- `mv` — Перемещает или переименовывает файлы/папки. Если указать то же самое место, но новое имя — файл просто переименуется.

- `rm` — Удаляет файлы навсегда.

**Специальные символы и флаги (В чём разница):**

- Знак `>` и `>>` (Перенаправление вывода):
  * `>` — Полностью стирает всё внутри файла и записывает туда новый текст (Перезапись).
  * `>>` — Не трогает старый текст, а аккуратно дописывает новую строчку в самый конец файла (Дозапись в лог).

- Команда `rm` и `rm -r` (Разница при удалении):
  * `rm имя_файла` — Удаляет только один конкретный файл. Если попробовать удалить так папку, Linux выдаст ошибку.
  * `rm -r имя_папки` — Флаг `-r` (Рекурсивно) заставляет команду зайти внутрь папки и принудительно стереть её вместе со всем содержимым.




### Пользователи и права доступа
- Обычные пользователи — имеют доступ только к своей домашней папке `~`.
- Суперпользователь `root` — главный администратор с абсолютными правами в системе.
- `sudo` (Superuser Do) — команда, позволяющая обычному пользователю запускать задачи от имени администратора.

**Виды прав (rwx):**
- `r` (Read / Чтение) — цифра `4`. Позволяет читать файл или смотреть список папки.
- `w` (Write / Запись) — цифра `2`. Позволяет изменять файл или удалять файлы в папке.
- `x` (Execute / Выполнение) — цифра `1`. Позволяет запускать файлы как скрипты или входить в папки.

**Команды управления доступом:**
- `ls -l` — подробный вывод списка файлов, показывающий буквенный код прав.
- `chmod` — смена прав доступа к файлу или папке.
  * Пример цифрами: `chmod 600 secret.txt` (владельцу — всё, остальным — ничего).
  * Пример буквами: `chmod o+r secret.txt` (остальным `o` добавить `+` чтение `r`).
- [х] `chown` — смена владельца файла или папки.

### Процессы

- `top` - интерактивный диспетчер задач

- `ps aux` - снимок всех процессов
- PID уникальный номер процесса
- STAT - состояние процесса
- %CPU, %MEM - нагрузка на процессор и память
- COMMAND - имя програаамы

**иерархия**
- `PID`, `PPID`, `PID 1`- systemd, прадедушка всех процессов, если процесс теряет родителя, его усыновляет PID 1.
- `pstree -p` - дерево процессов PID
- `pstree -p -s $$` цепочка родителей текущего терминала до PID1 ($$ = PID текущего bash)

**рождение процесса**
- `fork()` - системный вызов, создающий точную копию родительского процесса
- `exec()` - заменяет клон на новую программу. КОмбинация fork + exec стандартный способ запуска любой команды в Linux.

**поиск процесса:**
- `ps aux | grep nginx` - найти процесс по имени
- `ps aux | grep nginx | grep -v grep` - исключает сам grep из выдачи (-v = "всё кроме")
- `pgrep nginx` - вывести только PID
- `ps -o pid,ppid,stat,cmd -p <PID>` - показывает толкьо выбранные колонкидля конкретного PID

**завершение процесса:**
- `kill <PID>` - просьба завершиться, сигнал SIGTERM, №15. Программа может сохранить данные перед выходом. Можно убить сразу несколько процессов, если прописать из PID через пробел
- `kill -9 <PID>` - принудительное убийство, сигнал SIGKILL. Используется толкьо на зависших процессах.
- Ошибка " No such process (1)" - процесс уже завершон к моменту команды
- другие сигналы: SIGHUP (1) - перечитать конфиг, SIGINT (2) - прерывание с клавиатуры, SIGKILL (9) - принудительное убийство, нельзя перехватить, SIGTERM (15) - вежливая просьба завершиться, SIGSTP- пауза

**Состояние процесса, STAT:**
- `R` (Running) - выполняется прямо сейчас
- `S` (Sleeping) - спит, ждёт события.
- `D` (Uninterruptible) - застрял в ожидании диска/сети, нельзя убить даже kill -9
- `Z` (Zombie) - процесс завершился, но родитель не забрал код возврата. Лечится перезагрузкой родителя
- `T` (Stopped) - остановлен

**Фоновые задачи**
- `&` - запустить процесс в фоне, shell отвечает номером задачи и PID
- `Ctrl+Z` - пауза, `bg` - продолжить в фоне, `fg` вернуть на передний план
- `jobs` - список фоновых задач текущего терминала (взгляд shell'a; `ps aux`- взгляд всей системы)
- `jobs -l` - тоже самое + PID каждой задачи
-Статусы в уведомлениях: `Running` - работает, `Done` - завершился сам, `Terminated` - убит, `Exit 127` команда не найдена
-`+` в jobs - задача, с которой shell реботает в текущий момент

**Команда slepp:**
- `sleep 500` - ничего не делает, ждёт указанное число секунд и завершается. Полезно внутри скриптов для выдерживания пауз.

### Мониторинг и память

**top:**
- Load Averege (1,5,15 минут) средняя нагрузка на систему
- %Cpu(s): us (user) - код программ, sy (system) - ядро, wa (iowait) - ожидание диска, id (idle) - простой.
- Горячии клавишы `q` -  выход, `p` - сортировать по CPU, `m` - по памяти, `k` - убить процесс по PID,

- `htop` - улучшенный `top` (если установлен). Цветной, можно скроллить мышкой, искать процессы (F3), убивать (F9).

**RAM**

- `free -h` использование RAM, available - реально доступно, fre buff/cache - кэш

- `vmstat` 1 - мониторинг в риальном времени, si/so (swap in/out) > 0 означает нехватка ram

**Диски и файловая система**

- `lsblk` - дерево устроййст, типы: disk, part, loop, lvm
- `df -h` - свободное место в байтах
- `df -i` - свободные inode, inode- учётная карточка фалйа (методанные + адресса блоков)

- `LVM` - PV, VG, LV, команды: pvs, vgs, lvs, логика расширений lvextend (l- для процентов, L- абсалютных) + resize2fs

- `mount` - временное монтирование
- `/etc/fstab` - постоянное  монтирование. 6 колонок: [Устройство/UUID] [Точка монтирования] [Тип ФС] [Опции] [Dump(0)] [Pass(0,1,2)]
- `mount -a` - золотое правило пастоянного монитрования
