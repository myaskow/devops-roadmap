### Модуль 2: пройденные команды git
- init (инициализация папки гитом)

- cd (команда передвижения по корневым папкам)

- satatus (проверка статуса)

- echo (быстрое создание текстового файла с записаной строчкой символов)

- add (подготовка к сохранить, локально)

- commit (запечатать сохранение, локально. Флаги: -m, -a, --amend, --allow-empty)

- push (отправка запечатанного файла в облоко)

- code (быстрое открытие файла через терминал)

- branch (просмотр всех веток проекта. Флаги: -d)

- checkout (переключение между ветками. Флаги -b)

- merge (слияние веток)

- merge (слияние веток)

- diff (выводит разницу кода на диске и последним комитом)

- clon (снимает точную копию с публичного репозитория, со всеми комитами и ветками)

- fetch (проверяет облоко на наличие изменений)

- revert (создание нового комита, откатывающего прошлый)

- rebase (аналог merge но не ломающая историю комитов при сливании веток)
